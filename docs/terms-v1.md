# 競標平台使用者條款 v1

本條款內容已由平台營運者核可，版本識別為 `v1`。正式上線前仍須補齊平台營運者名稱及聯絡方式。

Runtime 顯示文案位於 `backend/terms/v1.txt`。更新條文時請同步更新兩份檔案。

## 一、適用範圍

本平台提供競標刊登、出價、得標通知、訂單、站內訊息及相關管理功能。使用者使用平台前，應閱讀並同意本條款。平台功能與交易規則以頁面當時明確顯示的內容為準。

本平台主要供個人使用。平台營運者、賣家與買家在個別交易中的法律關係及各自是否屬於企業經營者，仍應依實際事實與適用法律判斷；本條款不預先排除任何依法不得排除的權利或責任。

## 二、帳戶與資料

1. 使用者以 LINE Login 登入。使用者應維持帳戶安全，並對使用本人帳戶進行的操作負責；如發現未授權使用，應儘速通知平台。
2. 使用者應提供正確且最新的必要資料，不得冒用他人身分、建立多重帳戶規避管理或以不正當方式操作競標。
3. 平台為提供登入、競標、訂單、通知、安全維護及爭議處理所需，會處理 LINE 使用者識別碼、顯示名稱、頭像，以及使用者自行提供的商品、聯絡、寄送、訊息與交易資料。資料類別、利用目的、保存期間、當事人權利及聯絡方式，應另以完整的個人資料告知／隱私權政策說明；本條款不能取代該告知。

## 三、刊登與商品責任

1. 賣家應確保有權持有及出售刊登商品，並提供真實、清楚且足以辨識商品的名稱、描述、圖片、起標價格、加價範圍、時間、運送方式及費用。
2. 刊登活體商品時，賣家應確認其來源、飼養、持有、繁殖、運送及移轉符合所有適用法令，並提供必要的照護、健康及物種資訊。依法須許可、證明或禁止交易的物種不得刊登或交易。不得以平台規則取代主管機關要求。
3. 不得刊登違法、來源不明、禁止交易、侵害他人權利或具有欺騙性之商品；不得以不實帳號、假出價、串標或其他方式干擾競標公平。
4. 平台得在接獲檢舉、發現違法或為保障使用者及動物安全所必要時，暫停或關閉刊登、保全必要紀錄並進行管理處置；平台應依個案情況處理，不代表平台已確認任何一方違法或違約。

## 四、競標與得標

1. 每場競標的起標價格、最低及最高加價、開始與結束時間，以競標頁面顯示為準。所有時間由平台伺服器判定並以台灣時間顯示。
2. 使用者送出出價前應核對金額。出價符合平台顯示的加價區間且經伺服器接受後，即記錄於該競標。賣家不得對自己的商品出價；最高出價者不得以相同或更低價格重複出價。
3. 競標剩餘時間不超過一分鐘時收到有效出價，平台依系統規則將結束時間延長兩分鐘。競標是否結束及最終得標者，以平台伺服器紀錄為準。
4. 競標結束後，最高有效出價者為得標者。得標者應於得標後二十四小時內透過平台訊息聯絡賣家，並依訂單頁面指示完成付款及後續交易。多場競標可能依平台顯示的等待規則合併訂單。
5. 使用者不得因競標結果對其他使用者進行騷擾、威脅或站外詐騙。平台可保留出價、訂單及訊息紀錄以協助交易與處理爭議。

## 五、付款、出貨與交易爭議

1. 付款方式、金額、期限及支付服務提供者，以結帳及訂單頁面顯示為準。平台會依支付服務提供者的伺服器通知及驗證結果更新付款狀態，不以瀏覽器顯示作為付款完成依據。
2. 賣家確認訂單付款後，應依約定方式及合理期限出貨，並在平台填寫物流方式與單號。買家收到商品後應依訂單功能確認收貨；如有未收到、品項不符、運送或活體狀況等問題，應儘速透過平台訊息聯絡對方並保存必要證據。
3. 買賣雙方應先透過平台訊息協商。平台可依其管理能力要求雙方提出資料、限制帳戶或採取其他平台內處置；除依法或另有明確承諾外，平台不代替法院或主管機關認定實體爭議，也不保證任何一方必然履約或特定交易結果。
4. 本條款不限制消費者或其他使用者依強制適用法律享有的解除權、退款請求權、申訴權或其他權利。是否適用通訊交易解除權及法定例外，應依交易當事人身分、商品性質與當時有效法令個別判斷，不以本條款概括排除。

## 六、訊息、評價及檢舉

1. 站內訊息僅供與訂單相關的交易聯絡。使用者不得傳送違法、威脅、歧視、詐騙、侵害隱私或與交易無關的騷擾內容。
2. 評價應依真實交易經驗撰寫，不得以虛假交易、利益交換或脅迫方式操縱評價。評價與訂單綁定並依平台規則保存。
3. 使用者可依平台提供的方式檢舉競標或使用者，並應提供具體且真實的理由及資料。不得惡意或重複提出不實檢舉。

平台得依本條款、交易安全、法令要求或檢舉處理需要，調查可疑操作、暫停功能、關閉競標或限制帳戶。管理處置應以必要範圍為原則；使用者可透過平台提供的聯絡方式提出說明或申訴。封鎖帳戶不代表刪除依法或為處理既有交易、付款、爭議、安全及帳務所需保存的紀錄。

平台如需變更條款，應公告新版內容、版本及生效日期；若依法或依交易性質須另行通知或取得同意，平台應依規定辦理。需要重新接受最新版條款的功能，會在使用者接受新版本前暫停。使用者可停止使用平台；停止使用不影響已成立交易、未完成訂單或依法須處理的紀錄。

本條款依中華民國（台灣）法律解釋與適用。爭議應先透過平台聯絡方式協商；如協商不成，依適用法律及有管轄權的法院處理。本條款不以合意剝奪任何一方依法享有的法院管轄或消費爭議處理權利。
